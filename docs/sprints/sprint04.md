## Objetivo da Sprint

Avançar no desenvolvimento com foco em experiência do usuário (userflow), melhorias no dashboard, implementação de fluxos de produtividade, início do módulo de filtragem e configuração de DevOps.

---

## O que cada membro fez

| Membro | Contribuição |
|---|---|
| Gabriella | Melhorias visuais e funcionais do dashboard — refinamento de componentes, responsividade e ajustes de layout |
| Clara | Criou o userflow do sistema — jornadas do usuário, fluxos de navegação e estados das telas |
| Otávio | Iniciou a implementação do Módulo de Filtragem — lógica de filtro por tema, data e tipo de proposição |
| Lucas | Implementou o workflow de produtividade — automações com GitHub Actions para o ciclo de desenvolvimento |
| Edvaldo | Cuidou de DevOps — pipelines CI/CD, ambientes de staging e automação de deploys |
| João | Apoiou integração entre módulos e revisão técnica das entregas |

---

## Decisões Tomadas

- Userflow aprovado pelo time — referência oficial para desenvolvimento das telas do Front-End
- Dashboard com nova aparência validada pelo time — filtros serão integrados diretamente na interface
- GitHub Actions configurado para automação de testes e integração contínua
- Pipeline de CI básico configurado — deploy automático para ambiente de homologação em andamento
